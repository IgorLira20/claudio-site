Política de privacidade

Cláudio, assistente pessoal de Igor Lira. Atualizada em 29 de outubro de 2026.

O Cláudio é um app de uso privado: só o dono, Igor Lira, conecta a própria conta Google a ele. Esta página descreve o que o app faz com esses dados.

O que o app lê

  • Gmail, só leitura: remetente, assunto, data e o trecho de prévia dos e-mails da caixa de entrada. O corpo dos e-mails não é lido.
  • Google Agenda, só leitura: título, horário e local dos eventos do dia.
  • O endereço de e-mail da conta conectada, para identificá-la.

O app não envia, não apaga e não altera e-mails nem eventos.

Para que usa

Só para montar o resumo da manhã do dono. Para redigir esse resumo, remetente, assunto, trecho de prévia e eventos do dia podem ser enviados à API do Claude, da Anthropic, que devolve o texto do resumo.

O que guarda

  • O token de acesso concedido pelo Google, cifrado, num banco de dados no computador do dono.
  • O conteúdo dos e-mails e dos eventos não é guardado: é lido na hora de montar o resumo e descartado em seguida.

Com quem compartilha

Com ninguém, além do envio à API do Claude descrito acima. Os dados não são vendidos, não são usados para publicidade e não são usados para treinar modelos de IA.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Depois disso, o token guardado deixa de funcionar, e o dono pode apagá-lo do banco local.
